Part A
    1. Write a C program using the execl() system call that:
      i. Reads the name of a shell script from the keyboard.
      ii. Executes that script using /bin/sh.
      iii. Displays an appropriate error message if the script cannot be found or executed.
      iv. The shell script should prompt the user to enter three numbers, find and display the greatest of the three numbers.

    2. Write a C program that uses the appropriate Unix system calls to read the contents of a file and display it on the terminal. The program should prompt the user to enter the filename as input from the keyboard.

    3. Write the program to create five Child Processes using system call fork() and display their ids.

    4. Write a C program using Unix system calls to open a file for writing (create it if it does not exist). The program should read text from the keyboard and write it into file until Ctrl+D.

    5. Write a C program that registers a signal handler for SIGINT, SIGTERM, SIGHUP, SIGALRM, and SIGUSR1. The handler should receive each signal and perform some operation.
    6. Write a C program to demonstrate Critical section in process synchronization.

Part B
    1. Write a C program to implement First Come First Serve Scheduling algorithm to determine total waiting time, average waiting time, total turn around time and average turnaround time.
    2. Write a C program to implement Shortest Job First Scheduling algorithm to determine total waiting time, average waiting time, total turn around time and average turnaround time.
    3. Write a C program to implement Round Robin Scheduling algorithm to determine total waiting time, average waiting time, total turn around time and average turnaround time.
    4. Write a C program to simulate producer – consumer problem using semaphores.
